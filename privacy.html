Privacy Policy

Last updated: September 2026

"Issue#1" is a personal, non-commercial project used only by its developer.

Data collected

The application reads public video metadata (title, description, publish date, video link) from a single TikTok account that belongs to the developer, using the TikTok API. No data from other TikTok users is collected.

How the data is used

The collected video metadata is used only to send a notification message to a private Discord server owned by the developer. No data is sold, shared, or used for advertising.

Data storage

The application stores only the list of already-notified video IDs, to avoid duplicate notifications. No personal data beyond what is described above is stored.

Contact

For any question regarding this policy, please contact the developer via Discord.
